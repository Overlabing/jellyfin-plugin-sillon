General

When off, the Sillon apps do not offer the wishlist. Existing requests are kept.
Manually: requests are recorded and an administrator marks them as added. With Lidarr: the album is added to Lidarr, searched, and followed until it is in the library.
A request still waiting for a release after this many days is marked as failed.

Music folders

Used to find an album Lidarr has just imported. Leave both folders empty when Lidarr and Jellyfin see the same paths.
Different when Lidarr and Jellyfin run in separate containers that mount the library at different paths.

Catalogue allow-list

Limit the albums people can request to these MusicBrainz release groups. With no entry, the whole catalogue is offered.

    Defaults for added albums

    Webhook

    In Lidarr, open Settings, Connect, add a Webhook with this URL and the POST method, and tick On Grab, On Release Import and On Import Failure.
    Not the address in your browser if Lidarr lives elsewhere, for example http://jellyfin:8096 between containers.
    The URL carries a secret: treat it like a password.
